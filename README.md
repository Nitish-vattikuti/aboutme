## 🚀 Key Projects

### 📡 [Autonomous UAV SIL Simulation](https://github.com/Nitish-vattikuti/autonomous-uav-guidance)
A 3D Software-in-the-Loop (SIL) UAV guidance simulation featuring Weighted A* and RRT* path planners. Decouples flight simulation math from Ground Control Station (GCS) telemetry using a dual-process TCP/IP socket architecture, designed under Size, Weight, and Power (SWaP) edge computing constraints.

### 🔬 [SpectraFuse](https://github.com/Nitish-vattikuti/Spectrafuse)
A high-performance browser-based multi-spectral image fusion and object detection platform. Merges Visible, NIR, and TIR feeds using DWT and PCA transforms, running client-side GPU target tracking via TensorFlow.js (COCO-SSD) to guarantee absolute data privacy.

### 🖱️ [AI Virtual Mouse](https://github.com/Nitish-vattikuti/Virtual-Mouse)
Contactless hand gesture interface that translates real-time camera feeds into OS-level cursor commands. Uses OpenCV and MediaPipe Hand Landmarker for tracking 21 spatial landmarks and coordinates with a running-average buffer to filter out jitters.

### 📊 [InfraSight](https://github.com/Nitish-vattikuti/InfraSight)
AI-powered IT anomaly and failure prediction platform. Ingests real-time server telemetry into InfluxDB and trains reconstruction-based Autoencoders using Scikit-Learn to flag infrastructure failures up to 30 minutes before outages.

### 🏥 [Smart Healthcare Portal](https://smarthealthcare-1896.netlify.app/)
A mobile-optimized medical assistant helping patients log symptoms, triage emergencies, and locate nearest provider clinics using geolocation filters and interactive Leaflet.js maps.
